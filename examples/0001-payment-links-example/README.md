# Worked Example: Cycle 0001 — Payment Links Rework

A complete, compact example of a Cronos cycle folder, synthesized and anonymized from real production cycles. Fictional company ("Acme"), realistic dynamics: a mid-cycle amendment, a superseded ADR, a validator finding, a cautionary prompt entry, and a "shipped with conditions" release.

Read the files in order: plan → prompts → decisions → validation → retro. Note in particular how the retro's Promotion Candidates and Open Follow-ups sections are what the *next* cycle plans from.
