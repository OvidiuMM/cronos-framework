# Contributing to Cronos

Welcome to the Cronos Framework! We want your specialized `.cursorrules`, your prompt-chaining workflows, and your QA automation strategies. 

To keep this framework highly actionable and prevent "meeting-creep," we rely on strict guardrails for all community contributions.

## How You Can Help Optimize the Vibe-to-Verify Ratio

We are actively looking for contributions in the following areas:

* **Submit New Guardrails:** Did you build an incredible `.cursorrules` file for Next.js 15, Python FastAPI, or Rust? Submit it to the `/registry/cursorrules/` directory.
* **Refine Reset Triggers:** Help us optimize the 4-Hour Prompt Loop Stagnation metrics based on real-world team data.
* **Automate the Pipeline:** Contribute GitHub Actions or scripts to `/registry/ci-cd/` that automatically turn Slack/Discord alerts into Cronos Emergency Sync triggers.

## Pull Request Checklist

Before submitting a PR, please ensure your contribution meets our Definition of Done. All PRs must check the following boxes:

- [ ] **High Signal, Low Noise:** Your contribution is self-contained and does not introduce "meeting-creep" or unnecessary bureaucratic layers.
- [ ] **Timeboxed Cadence:** Any methodology or text adjustments strictly respect the core 1-Week Cycle cadence.
- [ ] **License Compliance:** You agree that any code, templates, or rules submitted to `/templates` or `/registry` will be licensed under the MIT License.
- [ ] **Formatting:** Markdown files are cleanly formatted, free of typos, and utilize clear headers.

Thank you for helping us build a faster, more deterministic future for AI Vibecoding!
